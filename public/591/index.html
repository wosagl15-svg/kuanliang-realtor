591 拋轉

貼上型錄內容和實際地址 → 產生 591 刊登資料 → 核對無誤才送出

  • ① 貼型錄
  • ② 核對資料
  • ③ 補必填
  • ④ 送到 591

1 型錄來源 資料全部來自電子型錄，這裡不推算、不補寫

要貼「文字」，不是貼網址
型錄站要登入，外部伺服器連不進去，所以丟網址一定失敗。
正確做法：在型錄頁按 Ctrl+A 全選 → Ctrl+C 複製 → 貼到下面。 整段貼進來就好，多餘的字不用刪。

2 核對表 每一欄都看得到來源，以及這個欄位有多可信

實測 從真實送出封包攔到的，確定正確 程式碼 欄位名確定、巢狀結構未驗證 未驗證 表單上有但 payload 欄位名未知 → 一律不填

可信度payload 欄位 說明型錄原文填入值
還沒產生資料。貼型錄內容按「產生 591 資料」，或按「載入範例」看看長什麼樣。

3 補必填 型錄給不了、或法律上必須你自己決定的

! 送出前必處理

  • 還沒產生資料。

4 送出封包 POST 591 刊登 API
